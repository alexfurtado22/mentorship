# 🧠 Mentorship Platform

A **Full Stack Django** project built with:

- 🐍 Django (Python)
- 🎨 Tailwind CSS v4
- ⚡ Alpine.js
- 🌐 HTMX
- 🐳 Docker for containerized development
- 🗃️ PostgreSQL
- ☁️ WhiteNoise + Brotli compression for static files
- 🚀 Gunicorn as the WSGI server for production

## 🚀 Features

- Authentication via **django-allauth**
- Dynamic front-end interactions using **HTMX** + **Alpine.js**
- Custom theme using Tailwind v4 and JIT mode
- Asset pipeline with collectstatic and Brotli compression via WhiteNoise
- Production-ready PostgreSQL setup
- Dev-friendly setup with runserver support

---

## 📦 Installation

bash
git clone https://github.com/alexfurtado22/mentorship.git
cd mentorship
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
